# UAE Mercury — Visa Expiry Calculator (Browser Extension)

Know exactly how many days your UAE visa has left.

Enter your visa expiry date and the extension instantly shows:

- ✅ **Days remaining** on your visa
- 📅 Your **grace period end date**
- ⚠️ **Overstay fine estimate** (AED 50/day) if you have already overstayed

Everything is calculated locally in your browser — **no data is collected, nothing is sent anywhere, and the extension requests no permissions.**

## 📥 Download & Install

- **Official stores:** listings on Microsoft Edge, Firefox, Opera and the Chrome Web Store are in review (submitted 12 Nov 2026) — this page will carry the live store links once approved.
- **Manual download:** grab the packages from the [Releases](https://github.com/uaemercury/uae-mercury-visa-calculator/releases) page:
  - `uae-mercury-visa-calculator.zip` — Chrome, Edge, Opera and other Chromium browsers
  - `uae-mercury-visa-firefox.zip` — Firefox
- **Manual install (Chrome/Edge):** download and unzip → open `chrome://extensions` → enable **Developer mode** → **Load unpacked** → select the folder.
